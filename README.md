# Pharmacy Management System

Application bilingue arabe–français de gestion de pharmacie sur Next.js 16, Node.js 24 et PostgreSQL 18.

Copier `.env.example` vers `.env`, lancer PostgreSQL, puis `pnpm install`, `node --import tsx src/db/migrate.ts`, `pnpm create-admin` et `pnpm dev`. `pnpm check` exécute les contrôles principaux. Voir [déploiement](Docs/DEPLOYMENT.md) et [exploitation](Docs/OPERATIONS.md).
