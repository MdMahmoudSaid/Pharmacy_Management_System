# Déploiement VPS

Installer Docker, cloner le dépôt et créer `.env` avec `POSTGRES_USER`, `POSTGRES_PASSWORD`, `POSTGRES_DB`, `MIGRATION_DATABASE_URL` (propriétaire), `DATABASE_URL` (utilisateur restreint `pharmacy_app`), `APP_DATABASE_PASSWORD` et `AUTH_FINGERPRINT_SECRET` aléatoire (32 caractères minimum). Lancer `docker compose -f compose.production.example.yml up -d --build`; les migrations utilisent uniquement le compte propriétaire, puis le serveur utilise le compte restreint. Créer l’administrateur (une seule fois) avec `docker compose -f compose.production.example.yml exec app node --import tsx scripts/create-admin.ts --name "Nom" --phone 21234567`; le PIN à 4 chiffres est demandé de façon masquée. Placer Caddy ou Nginx avec TLS devant `127.0.0.1:3000`, puis vérifier `/api/health`. Ne jamais committer `.env`.
